# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

The CBA-KB project takes the security of its code and data boundaries seriously.

If you discover a security vulnerability, credential leak, or sensitive data exposure:
1. **Do NOT open a public GitHub issue.**
2. Send a private advisory through GitHub Security Advisories or contact the maintainers privately.
3. Include details of the vulnerability, reproduction steps, affected files/commits, and any proposed fixes.

We will acknowledge receipt within 48 hours and work with you to remediate the issue promptly.
